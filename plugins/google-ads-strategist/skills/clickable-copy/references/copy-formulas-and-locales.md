# Clickable Copy — Intent Formulas & Multilingual Rules

On-demand formulas, examples, and locale-specific copy rules for `clickable-copy`.

## Intent-Class Copy Formulas

### Commercial Investigation Formulas (comparing options)

**Formula 1 — Differentiation lead**
```
H1: [Category] for [Specific Audience]
H2: [Unique Differentiator vs competitors]   (e.g. "Built for [audience], not [wrong-fit user]")
H3: [Proof point]                            (e.g. "Used by [N]+ [audience]")
D1: [Expanded differentiator] + [benefit to audience]
```

**Formula 2 — Price-anchor** (use when price is a real advantage; never hide it)
```
H1: [Category] from €[Low Price]
H2: [Category descriptor]
H3: [Why the price is this low]
D1: [Price breakdown] + [value justification]
```

**Formula 3 — Comparison lead** (generic framing — never name competitors)
```
H1: [Category] Without [Competitor Pain Point]
H2: [Your advantage]
H3: [Audience]
```

### Transactional Formulas (ready to buy)

**Formula 1 — Action verb + speed**
```
H1: [Action] [Category] in [Time]
H2: [Removing friction]                      (e.g. "No [Friction] Needed")
H3: [Price or starter offer]                 (e.g. "From €[Price]")
D1: [Step count] + [outcome on completion]   (CTA in extensions: Start Now / Order Now / Book Now)
```

**Formula 2 — Deadline urgency** (honest deadlines only — never fabricate "today only")
```
H1: [Category] — Deadline [Date]
H2: [Action verb] before penalty
H3: [Your speed vs deadline]
```

**Formula 3 — Risk reversal**
```
H1: [Action] [Category] — [Guarantee]        (e.g. "Money-Back if [Failure Condition]")
H2: [Value prop]
H3: [Social proof]
```

### Branded (Defensive) Formula

Simple and unambiguous — reclaim branded traffic without getting cute:
```
H1: [Brand] — Official Site
H2: [Primary category]
H3: [Clear CTA]
```

## Multilingual Copy Rules

Write each language **native-first** (separate RSA, headlines, and formulas — never machine-translate English into ET/RU):

- **Estonian (`et`)**: Always use proper Unicode diacritics (`ä, ö, ü, õ, š, ž`), never bare-ASCII fallbacks.
- **Russian (`ru`)**: Cyrillic throughout, never transliterated.
  - **Numeral grammar** (always verify — wrong agreement looks illiterate):
    - `1` (and `21`, `31`, ...): nominative singular (`1 год`, `1 минута`, `1 отчёт`)
    - `2–4` (and `22–24`, ...): genitive singular (`2 года`, `3 минуты`, `4 отчёта`)
    - `5–20` (and `25–30`, ...): genitive plural (`5 лет`, `10 минут`, `15 отчётов`)
  - **Character width**: Cyrillic renders wider than Latin — target 2–3 chars under the 30-char headline limit to avoid mobile cramping.
  - **Register**: Formal `"Вы"` (capitalized) for B2B/financial; lowercase `"вы"` for consumer.
  - **Price format**: EU convention `"€29"` (never `"29 евро"`, which wastes 4 chars).
- **English (`en`)** for non-native markets (e.g., e-residents): avoid idioms/colloquialisms ("save time", not "crush it").
